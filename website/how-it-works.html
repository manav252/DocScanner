How it works

Upload a photo of a page and see each step the app takes to find and flatten it. This page runs the app’s own detection code (scanner.js with OpenCV) in your browser. Your photo is not uploaded anywhere.

The steps

  1. 1Grayscale

    The photo is shrunk to 500 pixels and turned grey: colour is not needed to find edges, and small images are fast.

  2. 2Blur

    A Gaussian blur smooths paper texture and print so they do not count as edges.

  3. 3Edges

    Canny edge detection marks strong brightness changes in white; thresholds adapt to the photo’s median brightness.

  4. 4Outlines

    Every closed outline (orange) is checked: four corners, convex, big enough, sensible angles. The best one is the page (green).

    all outlineschosen page

  5. 5Corners

    Each side is refined along the strongest edge, then the four corners are shown on the photo. Red means no page was found.

  6. 6Flattened

    A perspective warp maps the four corners to a rectangle: the page as if scanned flat.

Then, in the app

You can drag the corners if they are off, pick a filter (Magic Color removes shadows; Black & White uses adaptive thresholding), add markup, recognise text, and export a PDF. On phones the same steps run natively with opencv_dart; a Python reference (scanner_core) and shared test photos keep all three versions in agreement.
